# Security Policy

## Reporting a Vulnerability

The OctaPDF security team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

### How to Report

You can report security vulnerabilities through the following channels:

1. **GitHub Security Advisory (Recommended)**:
   - Navigate to the [Security tab](https://github.com/DecoyINDIA/OctaPDF/security/advisories) in our repository.
   - Click on "Report a vulnerability".
   - Provide a detailed description of the vulnerability, reproduction steps, and impact.

2. **Direct Contact**:
   - Send your report to `security@octapdf.com`.
   - Please include as much information as possible about the vulnerability and reproduction environment.

### What to Include

When reporting a vulnerability, please provide:
- A clear description of the vulnerability.
- Proof-of-concept steps or files to reproduce the issue safely.
- Affected components and versions.
- Any potential impact on confidentiality, integrity, or availability.
- Suggested mitigations or patches if available.

### Response Time & Process

1. **Acknowledgment**: We aim to acknowledge receipt of vulnerability reports within 48 hours.
2. **Investigation**: Our team validates and investigates the report within 5 business days.
3. **Remediation**: We prepare a fix and keep the reporter informed of the remediation timeline.
4. **Disclosure & Attribution**: Once the fix is released, we publish an advisory and credit the researcher (unless anonymity is requested).

### Supported Versions

Only the latest release and the current `main` branch of OctaPDF are supported for security updates.

| Version | Supported |
| ------- | --------- |
| Latest release (`main`) | :white_check_mark: |
| Older releases | :x: |
